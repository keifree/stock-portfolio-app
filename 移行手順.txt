📦 別PCへの移行・継続手順
【STEP 1】現在のPCで「CSVファイル」をエクスポートする（重要）
アプリに登録されている銘柄データは、フォルダ内ではなく「今使っているブラウザのキャッシュ（localStorage）」の中に保存されています。そのため、フォルダをコピーしただけでは銘柄データは引き継がれません。

現在のPCで、アプリ右上の地球儀アイコン（共有設定）を開き、[ CSVエクスポート保存 ] ボタンを押して、現在のポートフォリオCSVファイルをPCにダウンロードしておきます。
【STEP 2】フォルダを別PCにコピーする（容量節約のコツ）
stock-portfolio-app フォルダをUSBメモリ等で別PCへコピーします。

容量節約のコツ フォルダ内にある node_modules というフォルダは、容量が非常に大きくコピーに時間がかかります。このフォルダはコピーから除外して（削除して）構いません。
【STEP 3】別PCのAntigravityでセットアップする
コピーしたフォルダを別PCのAntigravityで開きます（アクティブワークスペースに設定します）。
別PCのターミナルで以下のコマンドを実行し、必要なシステム部品を再構築します。
npm install （除外した node_modules が自動で再生成されます）
npm run dev （ローカルサーバーが起動し、ブラウザでアプリが開きます）
アプリが起動したら、右上の共有設定から [ 📥 CSVファイルからインポート復元 ] ボタンを押し、【STEP 1】で保存したCSVファイルを読み込ませます。
これで、別PC側でもまったく同じ開発環境と、これまでの本物の銘柄データを完璧に再現して作業を再開できます！
